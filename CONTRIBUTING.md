# Group collaboration

1. Assign an owner for RQ1, RQ2, and RQ3 in `README.md` and the shared Google Doc.
2. Use feature branches: `feature/rq1`, `feature/rq2`, `feature/rq3`, or a descriptive `feature/shared-...` branch.
3. Pull the latest `main` before starting work; avoid editing the same notebook simultaneously.
4. Keep reusable functions in `src/`. Commit experiment scripts and important reproducible figures, not raw data or local environments.
5. Open a pull request with a description of what changed, how you tested it, and whether AI assistance must be disclosed.
6. Have at least one teammate read the code before merging. Everyone remains responsible for understanding the complete project.
7. Do not put passwords, credentials, or private data in the repository.
